# VeniceHack v2.0.0 - Minecraft 26.2 "Chaos Cubed"

Gigantic Fabric cheat client: ~100 modules, ban-evade suite, staff watcher,
command system, friends, notifications, config profiles.

## Build (no PC needed)

1. Push this folder to a GitHub repo.
2. .github/workflows/build.yml builds automatically on push.
3. Repo -> Actions -> latest run -> Artifacts -> venicehack-jar.
4. Unzip, take the .jar WITHOUT "-sources".

## Install

Fabric Loader 0.18.4+ on Minecraft 26.2, plus Fabric API 0.152.2+26.2.

## In game

Right Shift opens the ClickGUI. ANTIBAN has StaffDetector and AntiBan.
Chat commands: .help .toggle .bind .friend .profile .panic .prefix
